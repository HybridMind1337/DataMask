# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within DataMask, please do not file a public GitHub issue.

Please send an email report directly to:
**security@hybridmindlabs.com**

Include in your report:
- The affected component or CLI command
- Reproduction steps or proof of concept
- Potential impact on production data safety or credential exposure

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
